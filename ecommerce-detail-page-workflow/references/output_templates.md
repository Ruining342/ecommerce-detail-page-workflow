## Template B — 最小白底素材扩展包

默认 3 张素材组，不拆成大量独立图片。

```markdown
# 最小白底素材扩展包

## 共同产品身份锁定
- 主身份源图：
- 必须保持：颜色、轮廓、比例、材质、结构、孔位/接口、零件数量、logo/标签位置。
- 证据边界：真实实拍角度 / AI 衍生可确认角度。
- 禁止：不得虚构背面、底部、内部、遮挡接口或其他隐藏结构。

## 01 白底精修主图
- 完整产品、纯白背景、准确身份、商业精修。

## 02 多角度组合图
- 同一画布 3–4 个明显不同的多机位角度；真实角度优先，可使用可见几何支持的 AI 衍生可确认角度。
- 不得用镜像充数，不得补造隐藏结构。

## 03 细节组合图
- 同一画布 3–4 个真实可见的材质、接口、结构、包装或功能细节特写。
- 细节特写不得新增原图不存在的部件、文字或功能。

生成规则：一次定义共同身份条件，连续生成三张素材组，不逐张等待用户确认。
```

## Template E — 最终交付记录

```markdown
# 最终交付记录

- 发布平台 / 语言：
- 文案状态：用户提供 / 用户已确认研究稿
- 素材组：白底精修主图 / 多角度组合图 / 细节组合图
- 页面数量、尺寸和顺序：
- 发生的崩溃纠错：无 / 第X屏字体崩溃 / 第X屏画面崩溃
- 长图尺寸：
- 拼接验证：PIXEL_MATCH=N/N
- 待确认参数：
- 用户判断项：设计感、高级感、构图偏好、吸引力与整体画面质量
```

## File naming

- `详情页文案确认稿.md`（仅缺信息分支）
- `01_白底精修主图.png`
- `02_多角度组合图.png`
- `03_细节组合图.png`
- `详情页紧凑执行清单.md`
- `第X屏_页面名称.png`
- `第X屏_崩溃纠错.md`（仅发生崩溃时）
- `商品详情页_完整长图.png`
- `最终交付记录.md`
