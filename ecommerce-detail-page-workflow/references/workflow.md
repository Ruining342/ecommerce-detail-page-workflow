# Fast Ecommerce Detail Page Workflow

默认使用 LEAN。入口只问发布平台，信息分流后连续推进。

## 1. Resume and special routes

- 主图快捷路线：只生成用户要求的主图数量，不进入完整详情页流程。
- PATCH：只重开受影响页面，不得重跑已确认阶段。
- 已有文案、素材、策划或分屏：从最近可用阶段继续，不重复上游步骤。

## 2. Product-image intake

收到产品图后只询问发布平台。不得批量追问品牌、型号、卖点、规格、价格、人群、场景、语言和参考风格。建议只问：

> 这套详情页准备发布到哪个平台？

用户回答后简短确认，例如“确认：发布平台为 TEMU，按英文详情页推进。”平台确认后判断产品信息是否充足，不再发第二轮问卷。

## 3. Product-information branch

### A. 有详情页信息和产品图片

满足以下最低条件即可走快速分支：能识别产品名称/类型；已知关键功能或卖点；与该品类直接相关的型号、规格或适配信息已经提供，或明确没有必要参数。

跳过调研，直接进入白底精修和多角度细节生成。把用户文字、包装可见信息和图片可见结构整理为内部紧凑事实表，不单独等待确认，也不重复询问已经提供的内容。

### B. 没有产品信息或信息不足

调研小红书和其他平台。来源优先级：

1. 产品或品牌官方页面、官方包装/说明资料。
2. 目标发布平台的同类商品页面。
3. 小红书同款/同类内容，用于用户语言、场景、关注点和视觉规律。
4. 其他主流电商平台同类商品，用于补充常见结构、适配、包装和页面模块。

只收集能影响详情页文案和结构的信息，结果重复时停止。公开互动信号是代理指标，不是平台官方排名。不得把多个相似产品的参数拼接成当前产品事实。

生成并交付给用户确认 `详情页文案确认稿.md`。确认前不得生成白底精修或扩展素材；这是缺信息分支唯一的强制确认节点。

确认稿结构：

- 发布平台、语言和产品定位
- 图片可见事实
- 来源支持的候选事实及链接
- 主标题、副标题和一句话价值
- 核心卖点与对应说明
- 目标人群、购买动机和使用场景
- 规格、尺寸、型号、适配、材质/成分或结构信息
- 使用/安装/清洁步骤
- 包装清单和购买提醒
- 6–8 屏详情页上屏文案
- 待确认事实与禁止使用的无依据宣传

用户确认后，冻结文案版本并直接生成最小素材组；不得重复调研或再次询问风格。

## 4. Minimal asset pack

默认 3 张素材组，目标是用 3 次有效生成覆盖后续页面，而不是产出大量单张角度图：

1. **白底精修主图**：纯白背景、完整商品、准确颜色/比例/结构、干净商业光线。
2. **多角度组合图**：同一画布内放 3–4 个由真实图片或可见几何支持的视角，角度有明显差异，不用镜像充数。
3. **细节组合图**：同一画布内放 3–4 个真实可见的材质、接口、结构、包装或功能部位微距。

一次定义共同产品身份锁定条件和三张图的差异提示词，然后连续生成，不逐张等待用户确认。未发生字体崩溃或画面崩溃就继续。不得扩展为更多前置素材；只有以下情况可增加：用户明确要求、产品由多个独立部件组成、三张分组图仍无法覆盖已确认详情页的必要结构。

有真实多角度图时全部作为身份依据。只有一张完整产品图时，一张能完整展示产品的清晰图片即可，不得强迫用户补拍；AI 衍生可确认角度不得补造背面、底部、内部、遮挡接口或隐藏结构。

## 5. Confirmed copy and downstream

确认文案与素材后直接向下推进：

```text
确认文案与素材
→ 6–8 屏策划
→ 一份统一视觉/身份提示词 + 分屏差异
→ Image2 逐屏生成
→ 字体/画面崩溃纠错
→ 无损拼接
→ 完整交付
```

每屏必须回答不同购买问题，并使用不同的画面证明：产品识别、核心利益、结构/原理、使用场景、步骤、适配/规格、细节证据、包装/收口。相邻屏不能只更换背景或镜像商品。

如果用户没有参考风格：缺信息分支直接复用文案调研中的视觉规律；信息齐全分支只做一次聚焦风格调研或使用平台/品类默认规则，不增加用户确认节点。

不要把统一提示词复制保存 N 次。中文标题宜不超过 12 字，英文标题宜不超过 7 个词；默认一屏一图。

## 6. 客观纠错门槛

只判断两类客观崩溃：

- **字体崩溃**：标题或关键信息大面积乱码、不可辨认、严重缺字或重叠，无法正常阅读。
- **画面崩溃**：商品主体缺失/严重变形、关键零件彻底错乱、人物肢体严重畸形、明显穿模/悬空/结构断裂，导致无法使用。

未出现字体崩溃或画面崩溃就直接输出。画面具体的效果和质量交给用户判断；不自动评价设计感、高级感、构图偏好、配色、吸引力、相似程度或整体画面质量。每屏最多自动纠错 1 次，纠错后直接输出；后续修改走 PATCH。

## 7. Assembly and delivery

完整详情页使用 `scripts/stitch_long_page.py` 按显式顺序无损拼接，要求 `PIXEL_MATCH=N/N`。

LEAN 默认交付：

- 缺信息分支的 `详情页文案确认稿.md`
- 白底精修主图、多角度组合图、细节组合图
- 独立分屏 PNG
- 完整长图 PNG
- 紧凑执行清单（平台、确认文案版本、分屏顺序和必要风险）

默认不创建过程报告、重复调研报告、N 份提示词、逐屏审查文件或额外素材包。
